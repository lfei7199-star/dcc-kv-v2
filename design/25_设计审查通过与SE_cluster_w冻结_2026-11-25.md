## 2. 冻结的形式化表述

```
SE_cluster_w  =  uniform-cluster bootstrap
              +  Hájek row-weighted replicate statistic

replicate:  Δ̂* = Σ_c k_c m_c ȳ_c / Σ_c k_c m_c      k_c ~ 均匀抽簇计数
目标参数:   Δ  = Σ_c m_c ȳ_c / Σ_c m_c  =  (1/200) Σ_i d_i
```

**你点出的那句判据，我原文抄进来当不变量**：

> 对于不等簇大小，必须把「抽簇机制」和「目标 estimand 的权重」分开定义，
> 否则很容易把 row-weighted target 变成另一种 cluster-weighted target。

这句话解释了为什么 `P(c) ∝ m_c` + 再恢复 `m_c` 权重是错的：两处 `m_c` 相乘，双行簇的贡献被**平方化**
（`Σ m_c² = 236 ≠ 200`，18 个双行簇被放权 1.18 倍）。抽簇概率回答「怎么抽」，
`m_c` 回答「抽到之后它在目标参数里占多重」。**混在一起时，回答第二个问题的东西被第一个问题污染了。**

`weight_by_size=False` 分支（簇等权）保留，但它的身份是**另一个参数**的证据，不是备选实现：
`design/24` §2.1 表 C 行，实测 `3.33` vs `5.00`，差 50%。

## 3. bug 的定性（写进证据链，不重开）

**blocking statistical implementation bug，已修复；不是数值精度问题。**

| 项 | B 方案（固定分母 200） | A 方案（Hájek） |
|---|---|---|
| `point` | −0.036000 | −0.036000 |
| replicate 均值 | −0.036003 | −0.035998 |
| `se` | **0.000758** | **0.000235** |
| `d_i → d_i + 5.0` 后 `se` | **改变** | **逐位不变** |
| `DEFF_empirical` | > 2.5（触发 `deff_empirical_implausible`） | 0.88 |

判据不是「两个数不一样」（那样只能说有分歧），而是第四行：**平移会改变 SE**
⇒ B 的估计量里含一个与水平成正比的伪方差分量 `Var(Σ k_c m_c)·μ²`
⇒ 它估的不是同一个目标参数的方差。方向还偏偏是「更大、更像保守」——
所以这个 bug 的危险性在于它会伪装成严谨。

## 4. 两门为什么不能合并

| 门 | 拦的是 | 对应的上游动作 |
|---|---|---|
| G6 `INVALID_SUMMARY_ONLY` | 记录里**没有**逐行配对分数 | 改采集脚本（数据本来没采） |
| G15 `INVALID_PAIRED_SOURCE` | 有 `d`，但两臂原始 `f1` **不可追溯/对不上**（`|stored_d − (f1_cand − f1_ref)| > 1e-12`） | 改导出逻辑（采了但被裁掉） |

合并成一门后，报告只剩一个 `code`，这两种情形就分不开了——而它们的修复责任人不同。
所以两门可同时出现在 `blocking`，CLI 逐个打印，不选其一。

G15 的价值也不在「字段在不在」，而在**复算**：把「有 `d` 字段」和「`d` 真是从两臂原始结果算出来的」区分开。
存 `d` 允许（`test_g15_stored_d_agreeing_is_accepted`），**只用 `d` 不允许**。

## 5. 主判决不变量

```
主判决  ←  仅  Δ̂ ,  SE_cluster_w ,  δ
诊断层  →  SE_iid / ρ_D / ρ_d / DEFF_model / DEFF_empirical
```

诊断层只能解释「为什么这个 SE 是这个大小」，不能替代它。具体禁止项：

- `model_misfit = true` ⇒ **只加旗标**，不改 `SE_cluster_w`、不退回 `SE_model`、不重算 `CI`。
- `DEFF_empirical < 1` ⇒ **只打 `deff_empirical_below_one` 旗标**，不进 `blocking`。
  聚类稳健方差**不要求** `DEFF > 1`；负的簇内相关确实能让设计方差小于独立基准。
  真正要防的是「`DEFF` 掉到 1 以下就回头微调权重」——那是用结果反推估计量。
- `ρ_D` 只做诊断，`ρ_d` 才进 `DEFF_model`（`1 + 0.18 ρ_d`）。
